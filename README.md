# Network-security-implementation-lab
Implemented and tested network security controls in Cisco Packet Tracer, including IPsec VPN connectivity, WPA2 wireless security, MAC filtering, IoT device security, DHCP, ACL-based access control, and guest network isolation.


The lab included a data center, ISP, public coffee-shop network,
and residential network.

## Security Technologies

- IPsec VPN
- WPA2 Personal / WPA2-PSK
- AES wireless encryption
- MAC address filtering
- Wireless network segmentation
- Guest WLAN isolation
- Access Control Lists (ACLs)
- IoT device security
- DHCP
- DNS
- FTP
- Network connectivity verification

## Data Center Security

- Examined edge-router access control policies
- Configured a wireless IoT smoke detector
- Enabled DHCP addressing
- Configured WPA2-PSK authentication
- Registered the IoT device with a centralized IoT server
- Verified network connectivity

## Public Wi-Fi VPN

Configured a VPN client on a device connected through a public
coffee-shop wireless network.

The VPN was used to securely access an FTP server located in
the remote data center.

Verified the IPsec security association and tested secure
file transfer through the VPN tunnel.

## Secure Home Wireless Network

Configured two separate wireless networks:

### HomeNet
- WPA2 Personal
- AES encryption
- Hidden SSID
- MAC address filtering

### GuestNet
- Separate guest SSID
- WPA2 Personal
- AES encryption
- Guest device authentication
- MAC address filtering
